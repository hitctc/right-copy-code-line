# 复制代码上下文

## 插件介绍

“复制代码上下文”是一款 VS Code 扩展，用于把选中的代码连同文件路径和行号一起复制到剪贴板。

它适合在以下场景中使用：

- 向 ChatGPT、Claude 等 AI 工具提问代码问题
- 向同事发送代码片段并保留文件位置
- 提交代码问题、Bug 反馈或技术讨论
- 避免手动补充文件路径和代码行号

## 使用目的

普通复制只能得到代码内容，接收者还需要额外确认代码来自哪个文件、位于哪些行。

本插件会自动补充这些上下文信息，让复制出的内容可以直接粘贴到聊天工具或问题描述中。

## 主要功能

- 复制工作区相对文件路径
- 自动生成代码片段的完整起止行号
- 选中半行时，自动复制完整起止行
- 保留原始代码内容和缩进
- 使用独立的“复制代码上下文”菜单项，不影响 VS Code 原生“复制”功能

## 安装方法

如果使用 VSIX 安装包：

1. 打开 VS Code。
2. 点击左侧“扩展”图标。
3. 点击扩展面板右上角的 `...`。
4. 选择“从 VSIX 安装”。
5. 选择 `right-copy-code-line-0.1.0.vsix`。
6. 安装完成后，按提示重新加载 VS Code。

## 使用方法

1. 使用 VS Code 打开一个项目文件夹。
2. 打开一个已经保存的代码文件。
3. 在编辑器中选中一段代码。
4. 右键打开菜单。
5. 点击“复制代码上下文”。
6. 将内容粘贴到聊天工具、Issue 或文档中。

## 复制结果示例

```text
src/utils/helper.ts
第 3-5 行
const a = 1;
const b = 2;
return a + b;
```

复制内容的顺序固定为：

1. 工作区相对文件路径
2. 代码行范围
3. 完整起止行代码

## 使用限制

- 只支持单段连续选区。
- 没有选中代码时，菜单项不可用。
- 没有打开工作区时，无法生成工作区相对路径。
- 未保存的临时文件不会执行复制。
- 插件不会覆盖或修改 VS Code 原生“复制”命令。
