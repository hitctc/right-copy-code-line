# 复制代码上下文

一个最小化的 VS Code 扩展：选中代码后，在编辑器右键菜单中选择“复制代码上下文”，即可复制以下内容：

1. 工作区相对文件路径
2. 代码片段的完整起止行号
3. 完整起止行代码

输出不使用 Markdown 代码块，示例：

```text
src/utils/helper.ts
第 3-5 行
const a = 1;
const b = 2;
return a + b;
```

## 使用边界

- 只支持单段连续选区。
- 即使只选中半行，也会复制完整的起止行。
- 没有选区时，菜单项禁用。
- 没有打开工作区或文件未保存时，不执行复制并提示用户。
- 不覆盖 VS Code 原生“复制”命令。

## 开发

```bash
npm install
npm test
```

在 VS Code 中按 `F5` 可启动扩展开发主机进行手动验证。
